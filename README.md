정적 HTML만 쓰므로 `.nojekyll`로 Jekyll 처리를 끕니다. 앱 안의 링크(`AppInfo` in `Views/AboutView.swift`)와
App Store Connect의 개인정보 처리방침·지원 URL이 이 주소를 가리키므로, 파일 이름을 바꾸지 마세요.
